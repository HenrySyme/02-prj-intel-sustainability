# AGENTS.md — Guidance for AI coding agents

Purpose
-------
This file gives concise, actionable guidance for AI coding agents working in this repository.

Quick summary
-------------
- Audience: Students who are beginners learning HTML and CSS.
- How to run: This is a static site — open [index.html](index.html) in a browser or preview in Codespaces.
- Key files: [index.html](index.html), [style.css](style.css), [img/](img/)

Agent conventions (keep it simple)
---------------------------------
- Provide the simplest, beginner-friendly code possible.
- Add short inline comments to explain code for learners.
- Avoid advanced CSS layout methods such as CSS Grid unless explicitly requested.
- Prefer readable, well-structured HTML and simple CSS (flexbox or stacked layouts when needed).

Links & references
------------------
- Project README: [README.md](README.md)
- Existing agent instructions (preserved): [.github/copilot-instructions.md](.github/copilot-instructions.md)

If uncertain, ask the student whether they prefer a simpler or more advanced solution.
